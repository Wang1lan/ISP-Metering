## 2. 对三项改动的建议

### 2.1 删除权重 1 开关：可行，但要承认功能边界

默认所有 block 权重为 1，保留权重 2、0 两个开关，符合“只标注特殊区域”的交互。

但原来的权重 1 开关不只是初始化工具，还可把任意已标注区域局部恢复为 1。删除后，第二版只能通过撤销最近一次操作或全部重置实现恢复，无法单独擦除较早某次标注的一部分。当前先接受这个限制，不额外添加橡皮擦或隐含鼠标操作。

颜色建议：权重 2 保留墨绿，权重 0 使用界面新指定的绿色，权重 1 完全透明、不叠色。默认状态由红色文字说明。标签、ROI 线条、覆盖层和图例必须保持同一含义，不能只改标签颜色。

### 2.2 增加 block 尺寸按钮：默认值必须和实际状态一致

当前是 `BlockButtonGroup` 内的四个互斥 ToggleButton，不是下拉框。继续使用该按钮组，启动时明确选择 16×16，不再弹出 `listdlg`。

导入前可先选尺寸；导入后也可切换，确认后基于完整原图重新裁剪分块。尺寸改变会使旧权重矩阵及撤销记录失效，因此必须清空；取消切换时按钮选择也必须恢复，不能出现“界面显示 32，内部仍是 16”。

### 2.3 增加撤销与重置：恢复旧值，不是删除一个圈

“撤销上个框选”应恢复最近一次有效赋权前的矩阵。若本次把之前权重 2 的区域改为 0，撤销应恢复为 2，而不是全部改成 1。

本版按最小实现定义为单步撤销：只保存最近一次有效赋权前的快照，撤销一次后按钮禁用；不实现连续多步撤销、Redo 或撤销重置。若以后需要连续回退，再改为历史栈。

“重置所有框选”应先确认，再把全部权重设为 1，并清空撤销记录。不改变原图、当前 block 尺寸、有效裁剪范围和网格。

## 5. 保持不变的数据规则

本节尺寸均用高×宽，不混用宽×高。

- 原图高 H、宽 W，方形 block 边长 B 只能为 8、16、32、64。
- `validH=floor(H/B)*B`，`validW=floor(W/B)*B`。
- 仅保留完整原图的左上区域，丢弃右侧和底部余数像素，不补边、不缩放原图来凑整数块。
- `WeightMatrix` 为 `double`，大小 `validH/B × validW/B`，元素限定 0、1、2，初始化全为 1。
- 矩阵 `(r,c)` 对应像素行 `(r-1)*B+1:r*B`、列 `(c-1)*B+1:c*B`。
- block 中心：`x=(c-0.5)*B+0.5`、`y=(r-0.5)*B+0.5`。
- ROI 使用中心点判定，继续采用已有 `inROI` 路径，不改成相交即选中。
- 重叠圈选以后一次写入为准，不累加权重。
- 临时 ROI 提交后删除；矩阵才是结果，不能从显示颜色反推权重。

## 6. 尺寸选择与导入流程

### 6.1 启动默认状态

在 `startupFcn` 显式同步：内部 `BlockSize=16`，按钮组 `SelectedObject=app.Button_4`。先完成数据和选择设置，再刷新按钮状态与高亮，不依赖用户点击触发初始化。

尺寸回调采用按钮组 `SelectionChangedFcn`，`event.NewValue`/`OldValue` 是按钮对象。建立按钮句柄到数值的明确映射，不用 `eval` 解析按钮文字，不给四个按钮再绑定重复的重建回调。

### 6.2 未导入图像时选择尺寸

只提交 `BlockSize` 和按钮组选择、高亮，不生成空权重矩阵。之后导入使用此值；用户不选择则一直为 16。

### 6.3 导入图像

1. 保留原有未导出修改的放弃确认和图像文件选择流程。
2. 读取图像，保留灰度/RGB校验及索引图转 RGB 的现有逻辑。
3. 用当前 `app.BlockSize` 构建临时 model，不再调用尺寸选择弹窗。
4. 读取、尺寸检查、模型构建、显示准备全部成功后提交；随后清空撤销快照并关闭两个开关。
5. 取消、损坏文件或过小图像均保留旧图、矩阵、尺寸、选择、撤销记录及脏标志，不提前清空。
6. 新图沿用用户当前尺寸，不在每次导入时强制改回 16。

### 6.4 已导入图像后切换尺寸

1. 保存旧 B、旧选择对象、旧模型与撤销状态；相同 B 直接返回，禁止意外清空权重。
2. 判断新 B 是否能形成至少一块；不能则提示并恢复旧选择。
3. 若当前存在非默认权重或可撤销记录，弹窗说明“更改 block 尺寸将重置所有权重并清空撤销记录，是否继续？”，默认选择取消。
4. 此确认不能只检查 `IsDirty`：即使权重已经导出，切换仍会清除当前标注，应提示。
5. 同意后从 `OriginalImage` 重新计算裁剪、中心坐标、全 1 矩阵和显示对象。禁止从旧 `ValidImage` 再裁剪，否则从 B=64 切回 B=8 时会丢失本应重新纳入的像素。
6. 全部成功后提交新模型、按钮选择和高亮，清空撤销；这属于新的待导出配置，设置 `IsDirty=true`。
7. 取消或失败则恢复原选择及全部旧状态。UI 显示的 B 和内部 B 必须一致，不能只还原其中一个。

执行期间使用现有 `IsBusy` 防止回调重入。尺寸选择回调若因忙碌而拒绝，也应把按钮组选择同步回已经提交的 B。

## 7. 两个权重开关与颜色

沿用现有“一次开启 → 画一次闭合自由 ROI → 提交 → 两个开关都关闭”的交互，不额外引入持续画笔模式。

ROI 绘制中锁定导入、导出、尺寸按钮、撤销、重置及权重开关。完成、取消或异常后通过统一清理方法恢复。

| 权值 | ROI/标签/覆盖 RGB | 覆盖 Alpha |
| --- | --- | --- |
| 2 | `[18 84 79]/255`，墨绿，与 `Label_2` 一致 | 0.25 |
| 0 | `[42 131 95]/255`，绿色，与 `Label_3` 一致 | 0.25 |
| 1 | 透明，CData 可设任意中性色 | 0 |

`weightOverlayData` 按 `WeightMatrix(:)+1` 索引时，调色板行顺序必须是 **0、1、2**。新透明度数组按此顺序为 `[0.25;0;0.25]`。不能把 UI 中的开关显示顺序误当成调色板索引顺序。

建议右侧标题第二行使用“墨绿=2，绿=0，不叠色=1（默认）”。保持现有标签配色，不擅自换成旧文档的橙红/蓝色。字体说明和数值有助于区分相近绿色；实际可辨性在 MATLAB 预览验收。

## 8. 单步撤销的数据结构与行为

### 8.1 最小新增状态

保留现有图像、几何、矩阵、图形句柄和忙碌状态。只需新增一个私有属性：

`UndoWeightMatrix = []`：最近一次有效圈选之前的完整权重矩阵；空数组表示不可撤销。

单步方案使用完整矩阵快照，比维护 ROI 列表或索引差分更简单。2160×3840、B=8 时矩阵为 270×480；一份 double 快照的数据量为 1,036,800 字节，约 0.99 MiB，不含对象管理开销。无需保存原图快照或 4K 像素级掩模。

不另设冗余 `HasUndo`；用 `~isempty(UndoWeightMatrix)` 派生。可增加 `clearUndoRecord`、`undoLastSelection` 两个辅助方法。

### 8.2 什么时候记录快照

“有效圈选”必须满足：ROI 有效、至少选中一个 block 中心，且至少一个所选 block 的权值实际发生变化。

处理顺序：

1. 完成 ROI 有效性与中心点判定。
2. 若没有实际数值变化，直接结束，不修改旧快照，也不改 `IsDirty`。
3. 在局部变量保留当前矩阵 `before`，构造赋权后矩阵 `after`。
4. 成功提交并刷新后，将 `UndoWeightMatrix` 更新为 `before`，设置 `IsDirty=true`。
5. 如更新显示失败，应还原矩阵、原撤销快照和旧标志，并恢复显示；不能报告成功但数据与画面不一致。

取消 ROI、退化 ROI、圈中零个中心以及对同权重区域重复赋值都不消耗已有撤销机会。

### 8.3 点击“撤销上个框选”

1. 忙碌、无图或快照为空时不执行，按钮平时应已禁用。
2. 防御性确认快照大小与当前矩阵一致，不一致时不得直接套用，清理无效记录并提示。
3. 恢复 `WeightMatrix=UndoWeightMatrix`，刷新同一个覆盖层对象。
4. 成功后清空快照，禁用撤销按钮，标记 `IsDirty=true`；不弹确认，不改变尺寸和网格。
5. 若失败，保留撤销前的数据及快照，以便恢复后重试。

例：先将 A 区域赋 2，再把 B 区域赋 0。撤销 B 后，A∩B 恢复 2，B\A 恢复 1，A\B 仍为 2。不能直接将 B 全改为 1。

连续两次有效圈选会用新快照覆盖旧快照。撤销第二次后不能继续撤销第一次；按钮 Tooltip 可说明“仅撤销最近一次有效赋权”。导出不清空快照，导出后仍可撤销，但需重新导出才能保存新结果。

## 9. 全部重置与状态保护

`Button_8` 调用修改后的 `resetAllWeights`：

- 只有存在非 1 权重或可撤销记录时才启用。
- 弹窗明确说明“全部权重恢复为1，并清空撤销记录；该重置不可撤销”，默认取消。
- 确认后恢复全 1，清空快照、临时 ROI，关闭两个开关，刷新覆盖层。
- 原图、B、裁剪、网格保持不变。撤销按钮禁用。
- 取消时权重、快照、脏标志完全不变。
- 若全为 1 且无历史，操作为无变化，不制造撤销记录或弹无意义的确认。

删除 Ctrl+R 对重置的响应和标题提示。不得因删除旧 `WindowKeyPressFcn` 而破坏 Freehand 的取消交互；必须实测 Esc 取消、窗口关闭与清理行为。保留 `UIFigureCloseRequest` 中现有 ROI 清理。

## 11. 原有显示与导出继续复用

继续使用逻辑分块，保留一幅有效图像、一幅 block 分辨率覆盖图、一个 NaN 分隔的网格线对象，绘制时最多一个临时 ROI。撤销和重置只刷新覆盖层，不重建图像和网格。

保留 `BlockCenterX/Y` 与原图像素坐标的对应；显示缩放不改变矩阵行列。当前代码包含单行/单列 block 的覆盖坐标特殊分支，不能在本次改动中未经验证就删除或假定它正确；需增加 1×1、1×N、N×1 验收。

MAT 导出仍保存独立变量：`WeightMatrix`、`blockSize`、`originalImageSize`、`validImageSize`、`sourceImageName`。只导出当前状态，不导出 `UndoWeightMatrix`、ROI、图形句柄或完整源目录。

导出全 1 矩阵合法；全 0 矩阵也可保存，但应提示“全0权重不能直接用于归一化加权测光”，不得静默改回1。该提示不代替下游算法的零分母保护。
